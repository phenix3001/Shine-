# Серебряный магазин и рекомендации — 20 октября 2026

- Один общий верхний блок на всех страницах: логотип, поиск, тема и уведомления.
- Главная, карточка товара, корзина, профиль, «О нас», кабинет продавца, импорт и восстановление пароля имеют одинаковые внешние отступы и ширину.
- Поиск на сторонней странице открывает каталог по Enter или кнопке. В каталоге результаты меняются при вводе; запрос хранится в URL.
- Витрина, рекомендации и публичные коллекции показывают только опубликованное серебро. Материал важнее пробы: встречавшиеся в импорте золотые товары с пробой 925 скрыты.
- Золото, смешанные материалы и сомнительные позиции не удалены и не переименованы. Продавец видит исходные записи и пометку, почему они скрыты.
- В форме нового товара материал уже указан как серебро. Оформление заказа дополнительно проверяет серебряный состав на сервере.
- В каталоге показывается один вариант каждой модели вместо повторов разных размеров/веса. Счётчик количества и варианты фильтров учитывают это правило.
- Популярность зависит от открытий страницы товара. Фоновая загрузка каталога и фотографий не увеличивает просмотры.
- Сервер учитывает одно открытие товара на посетителя/аккаунт за UTC-сутки. Повторный эффект React и обновление страницы не увеличивают счётчик ещё раз. Клиент не может записать произвольное значение `views_count`.
- Для гостя используется случайный идентификатор устройства. История хранится в Supabase; IP-адреса не нужны. У аккаунта собственная история, чужая история после выхода не показывается.
- Рекомендации есть и в пустой корзине. Без истории показываются популярные изделия, с историей учитываются категории и бренды просмотренных товаров.
- Товары корзины и другие размеры тех же моделей исключаются из рекомендаций. Равные по популярности варианты перемешиваются стабильным seed на сеанс; сортировка по цене сохраняет правильный порядок.
- В кабинете продавца отображаются просмотры товара.

## Проверки

- `npm run build`, `npm test` (30 тестов), `npm run kaspi:check` — успешно.
- 56 проверок настоящих SQL-функций в изолированном PostgreSQL/PGlite: состав, RLS/права, дедупликация, история, популярность, seed, цены, пагинация, рекомендации, заказ и импорт.
- 112 сочетаний маршрута, размера экрана и темы: единая шапка, совпадение ширины, нет ошибок JavaScript, горизонтального переполнения и замечаний Axe.
- В браузере на production preview и dev/StrictMode подтверждены гостевые рекомендации, персонализация, отсутствие вариантов товара из корзины, одно событие на открытие, повтор после refresh, повторная загрузка после ошибки и работа seed.
- Публичный API живого проекта: 2759 уникальных серебряных моделей, 8 рекомендаций, в материале только серебро. Эти проверки не создавали реальные события просмотров или заказы.
- `node --test scripts/catalogFilters.test.mjs` — успешно: характеристики, галочки, счётчики категорий, сортировки и стабильная пагинация на живом каталоге. Модель в нескольких категориях учитывается отдельно в каждом фильтре, поэтому счётчики категорий не складываются в общий итог.

Изменения включены в снимок проекта «Shine beta 1.0.0 — версия 1» (`1.0.0-beta.1`) для ветки `Shine-beta-1.0.0`. Дальнейшие commit и push выполняются только по просьбе пользователя.
