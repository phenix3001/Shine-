## Простой вариант оплаты через Kaspi

Kaspi разрешает разместить ссылку на удалённую оплату на сайте.
Ссылка относится к конкретной точке продаж:
[Как получить ссылку](https://guide.kaspi.kz/partner/ru/pos/payments/remote/q2019).

1. В Kaspi Pay открыть «Удаленная оплата» → «Ссылка для оплаты».
2. После создания заказа на сайте показывать сумму, номер заказа и кнопку перехода по этой ссылке.
3. Покупатель вводит сумму в Kaspi.kz и указывает номер заказа в сообщении.
4. Продавец сверяет поступление, сумму и заказ, затем подтверждает оплату в магазине.

По обычной ссылке сумму вводит сам покупатель. Кассир получает уведомление о платеже:
[Официальное описание](https://guide.kaspi.kz/partner/ru/pos/payments/remote/q2098).
Нажатие кнопки или возврат на сайт сами по себе не доказывают оплату.

Для одного магазина публичную ссылку можно добавить через переменную окружения.
Для нескольких продавцов потребуется хранить ссылку каждой точки в настройках соответствующего продавца в Supabase,
добавив поле через отдельную миграцию.

## Если нужна автоматическая проверка

Сначала нужно согласовать доступный магазину вариант интеграции с Kaspi.
Для сервиса «Платежи на Kaspi.kz» поставщик подаёт заявку на сотрудничество:
[Подключение сервиса](https://guide.kaspi.kz/partner/ru/payments/distributor/connection/q4389).
Одобрение и условия определяет Kaspi; наличие ссылки на удалённую оплату само по себе не означает доступ к API.

После получения официального протокола серверную обработку можно разместить в Supabase Edge Functions:
проверять подлинность подтверждения, номер заказа, сумму и валюту, исключать повторную обработку одной транзакции.
Статус оплаты обновляет сервер. Платёжные поля и ограничения доступа добавляются через миграции.

В этой задаче платёжная интеграция не подключалась: пока подготовлено описание вариантов.
