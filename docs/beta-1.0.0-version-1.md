# Shine beta 1.0.0 — версия 1

Версия пакета: `1.0.0-beta.1`. Ветка: `Shine-beta-1.0.0`.

Это полный снимок исходного проекта: приложение, изображения, шрифты, зависимости в lock-файле и миграции Supabase.

- Только серебряные украшения в публичном магазине.
- Общая верхняя панель и одинаковая ширина страниц.
- Популярные и персональные рекомендации в корзине, учёт просмотров, устранение повторов моделей.
- Круглый аватар с фото аккаунта или белой буквой на бирюзовом фоне.

Подробности каталога и базы: [описание изменений](silver-discovery.md).

## Запуск копии

1. Установить Node.js 22.12 или новее и выполнить `npm ci`.
2. Создать локальный `.env` по `.env.example`, указать настройки своего Supabase.
3. Запустить `npm run dev`.

Для Vercel используются `npm run build`, папка `dist` и переменные `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` в настройках проекта. `vercel.json` обеспечивает прямое открытие и обновление вложенных страниц.

Секреты окружения, `node_modules`, сборка `dist` и временные данные в снимок не входят. Данные и настройки облачного Supabase сохраняются отдельно от Git.
